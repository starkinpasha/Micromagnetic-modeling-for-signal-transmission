# Micromagnetic-modeling-for-signal-transmission
MUMAX3-Matlab
Основная задача проекта — исследовать пространственное распределение спиновой волны после взаимодействия с отверстием в ферритовой плёнке и изучить формирование сверхнаправленного луча.
В работе рассматривается возможность управления характеристиками распространяющейся спиновой волны за счёт параметров возбуждения и геометрии структуры.
Общий вычислительный процесс:
Построение модели в MuMax3
Задание материала и геометрии
Установка магнитного поля
Релаксация магнитного состояния
Возбуждение спиновой волны
Численное моделирование
Сохранение результатов в OVF
Импорт данных в MATLAB
Обработка результатов
Построение пространственных карт
MuMax3
Основной файл моделирования:
42.54.mm3
В нём выполняются:
создание расчётной сетки;
построение геометрии ферритовой плёнки;
создание отверстия;
задание параметров материала YIG;
задание статического магнитного поля;
релаксация магнитизации;
сохранение основного состояния;
задание источника возбуждения;
моделирование распространения спиновой волны;
сохранение пространственного распределения магнитизации.
Результаты моделирования сохраняются в формате .ovf.
Обработка данных в MATLAB
Для обработки результатов используется скрипт:
spatial_maps.m
Скрипт позволяет выбрать несколько файлов .ovf и автоматически обработать их.
В качестве эталонного состояния используется:
groundstate_m.ovf
Для каждого выбранного состояния выполняется сравнение с основным состоянием магнитизации.
Рассчитываются пространственные распределения:
динамической составляющей магнитизации;
интенсивности магнитного отклонения от основного состояния.
Расчёт пространственного распределения
Для каждого узла расчётной сетки определяется изменение магнитизации относительно основного состояния.
Используемая величина интенсивности определяется как:
(mx - mx₀)² + (mz - mz₀)²
где mx₀ и mz₀ — компоненты магнитизации основного состояния.
Также анализируется изменение mz относительно основного состояния.
Визуализация
MATLAB автоматически формирует два типа изображений.
Карта динамической составляющей
Показывает пространственное распределение изменения компоненты магнитизации.
Результаты сохраняются в формате:
phase_plot_*.png
Карта интенсивности
Для визуализации интенсивности используется логарифмическая шкала.
Результаты сохраняются как:
intensity_log_plot_*.png
Все обработанные изображения сохраняются в директории:
ProcessedData/
Импорт OVF
Для загрузки данных из OVF используется функция:
oommf2matlab.m
Она считывает параметры расчётной сетки и компоненты векторного поля из OVF-файла и преобразует их в MATLAB-массивы.
В результате формируется структура с координатами расчётной сетки и компонентами магнитного поля/магнитизации
